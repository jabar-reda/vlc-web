## طريقة الاستخدام

###  عبر الإنترنت (GitHub Pages)

افتح **https://jabar-reda.github.io/vlc-web/** في أي متصفّح. هذا كل شيء — يعمل عبر HTTPS من أي مكان.

###  محليًا (file://)

انقر نقرًا مزدوجًا على `index.html` (أو افتحه في أي متصفّح عبر `file://`). لا تبعيات، لا `npm install`، ولا خطوة بناء.

## المزايا

| الميزة | الوصف |
| --- | --- |
|  فيديو /  صوت | تشغيل HTML5 لصيغ الويب الشائعة (MP4, WebM, MP3, WAV, OGG, …) |
|  صور | عرض PNG, JPG, GIF, WebP, SVG وغيرها |
|  نص وترجمات | قراءة TXT, MD, SRT, VTT, ASS, CSV, JSON, سجلات الحاسوب… |
|  قوائم تشغيل | فتح ملفات `.m3u` / `.m3u8` / `.pls` (روابط محلية وبعيدة) |
|  بثّ عن بُعد | إفلات أو تحميل رابط HTTP(S) وبثّه مباشرة (http/https، ويلزم امتداد وسائط) |
|  سحب وإفلات | إفلات أي عدد من الملفات في أي مكان على الصفحة |
|  قائمة التشغيل | انقر على أي عنصر لتشغيله، تقدّم تلقائي، مسح بزر واحد |
|  خلط /  تكرار | تشغيل عشوائي أو متكرر |
|  التحكم | تشغيل/إيقاف مؤقت، إيقاف، التالي/السابق، ترجيح ±10 ثوانٍ |
|  الصوت | مؤشر مستوى الصوت مع زر كتم |
|  ملء الشاشة | ملء الشاشة بنقرة واحدة مع أيقونة تُحدَّث تلقائيًا |

## اختصارات لوحة المفاتيح

| المفتاح | الوظيفة |
| --- | --- |
| `Space` | تشغيل / إيقاف مؤقت |
| `` / `` | ترجيح للخلف / للأمام 10 ثوانٍ |
| `` / `` | رفع الصوت / خفضه |
| `N` / `P` | التالي / السابق |
| `M` | كتم / إلغاء الكتم |
| `F` | تبديل ملء الشاشة |
| `S` | إيقاف |

## الصيغ المدعومة

كل ما يدعمه مشغّل الوسائط في المتصفّح يُقبَل عند اختيار الملفات وفي منطقة الإفلات:

- **فيديو**: MP4 (H.264), WebM (VP8/VP9), MKV, AVI, MOV, OGV, MPEG, M2TS, TS, FLV, WMV, 3GP وغيرها.
- **صوت**: MP3, WAV, M4A, AAC, FLAC, OGG, OPUS, WMA, AIFF, MIDI, AMR وغيرها.
- **صور**: PNG, JPG, GIF, WebP, SVG, BMP, ICO, AVIF, TIFF, JXL.
- **نص / بيانات**: TXT, MD, SRT, VTT, ASS, CSV, JSON, XML, ملفات السجلات، وأي امتداد — تُفتح الملفات غير المعروفة كنص.
- **قوائم تشغيل**: M3U, M3U8, PLS.

> **ملاحظة**: يمكن للمتصفّح تشغيل ما يدعمه أصليًا فقط. الحاويات النادرة مثل MKV أو AVI أو FLAC تُضاف إلى قائمة التشغيل لكنها قد لا تُفكَّك دون إضافة برنامج ترميز. استخدم تطبيق VLC المكتبي لتلك الصيغ. الإفلات المباشر لرابط يقبل `http(s)` فقط — يُصنَّف الرابط حسب امتداد مساره، فيلزم أن يحمل امتداد وسائط مدعومًا؛ أما البروتوكولات الأخرى فتُرفض مع رسالة. أما الروابط غير الـ HTTP التي تُوجد *داخل* ملفات قوائم التشغيل فتُضاف إلى القائمة لكن لا يمكن بثّها في المتصفّح.

## التصميم

- لوحة أبيض وأسود خالصة مع لون رمادي خفيف للعناصر الثانوية.
- خط أحادي المسافة (monospace) لإحساس تقني يُذكّر بالطرفية.
- أيقونات **Lucide** الخطّية (https://lucide.dev) — صور SVG مبنية على حدود مدمجة في `index.html` تستخدم `currentColor`، فتلائم تلقائيًا ثيمة الأبيض على الأسود، بما في ذلك حالات التفعيل المعكوسة.

## البنية المعمارية

كل شيء يعمل من نص `<script>` كلاسيكي واحد في `app.js`، لأن المتصفّحات تمنع `import` لوحدات ES على `file://`. ملف واحد مدمج يُبقي المشغّل يعمل دون أدوات بناء، ودون تبعيات، ودون خادم. تُحدَّث حالة الواجهة من أحداث الوسائط (`timeupdate`، و`play`/`pause`، و`loadedmetadata`/`durationchange`، و`volumechange`)، وتُعاد رسم قائمة التشغيل عند تغيّر محتوياتها أو العنصر الحالي، وتُحمَّل الملفات عبر `URL.createObjectURL` مع إلغاء روابط الكائن عند الإغلاق.

## بنية المشروع

```
vlc-web/
├── index.html   # ترميز الصفحة + أيقونات SVG المدمجة
├── style.css    # التنسيق (واجهة أحادية اللون بأحرف أحادية المسافة)
├── app.js       # كل منطق المشغّل (ملف واحد، دون استيرادات)
└── assets/      # الشعار، الأيقونة المفضلة، لقطة الشاشة
```

## دعم المتصفّحات

- يعمل في المتصفّحات الحديثة Chrome وEdge وFirefox وSafari — على سطح المكتب والجوال.
- يعمل بالكامل من `file://` — دون الحاجة إلى خادم.
- يشغّل ما يدعمه مشغّل الوسائط في متصفّحك أصليًا (انظر [الصيغ المدعومة](#الصيغ-المدعومة)).
